## 1. RAG 도입 필요성 검토

### 제안된 AI 의견 요약
- 고전 명리 문서(한문) RAG → 비효율
- 필요한 데이터: 명리 규칙 데이터, 해석 문장 데이터, 사주 사례 데이터
- 데이터 확보: 명리 블로그 크롤링, 유튜브 강의 자막, 명리 강의 PDF
- 추천 구조: `사주 계산 → 특징 추출 → Rule/RAG 검색 → LLM 해석 생성`

### 검토 결론: 현재 RAG 불필요

**핵심 이유**: RAG가 필요한 조건은 "어떤 내용을 가져와야 할지 계산 전까지 모른다"는 상황인데, 이 프로젝트는 다르다.

사주를 계산하면 `일간`, `격국`, `용신`, `희신` 같은 값이 이미 확정되므로, **어떤 콘텐츠를 가져와야 하는지 계산 결과가 곧바로 알려준다**. 이는 의미 유사도 검색(벡터 DB)이 아닌 **결정론적 조회(deterministic lookup)** 이다.

| 비교 항목 | RAG (벡터 DB) | ContentLoader 연결 |
|---|---|---|
| 구현 복잡도 | 높음 (임베딩, 벡터 DB, 청킹) | 낮음 |
| 현재 필요성 | 불필요 | 즉시 필요 |
| 해석 품질 향상 | 불확실 | 확실 |

### RAG가 필요해지는 시점 (미래)
- 명리학 책/블로그/강의 자막 등 **비구조화된 대량 텍스트**가 확보됐을 때
- "내 사주에서 올해 이직 타이밍은?" 같은 **자유형 질문** 처리 필요 시
- 콘텐츠가 너무 많아 프롬프트에 다 못 넣을 때

## 2. 현재 아키텍처 문제점

### 현재 흐름
```
계산 결과 → GPT (ContentLoader 콘텐츠 없이 해석)
```

`ContentLoader`에 일간별 성격 설명, 격국 해설, 용신/희신 콘텐츠가 이미 구조화된 JSON으로 존재하는데, **`prompt_builder.py`에 단 한 줄도 연결되어 있지 않다**.

`manse_ori/testResult/` JSON 파일들 → UI 출력 전용으로만 사용 중

## 3. 프롬프트 엔지니어링 개선 검토

### 제안된 AI 의견 요약
1. `핵심 판단 요약` 블록 추가 (신강약, 월령, 오행 과부족 등)
2. 사용자 질문 우선 규칙 강화
3. 신살 보조화, 핵심 구조(일간/월령/오행/십신/대운) 우선화
4. 출력 형식 표준화
5. 2단계 생성 (분석 메모 → 사용자 해설)
6. RAG를 핵심 판단 포인트별 짧은 근거 검색에 활용

### 검토 결론

**동의하는 부분:**
- `핵심 판단 요약` 블록 추가 → 가장 가치 있는 제안. 현재 코드는 날것의 데이터만 넣어 GPT가 스스로 중요도를 판단해야 함
- 신살 보조화: 신살은 핵심 구조를 보조하는 요소로 다루는 것이 맞음
- 질문 중심 재구성 및 출력 형식 표준화: 장기적으로 필요

**이 프로젝트에서 가장 중요한 포인트가 빠져 있음:**
ContentLoader 콘텐츠를 프롬프트에 주입하는 방법을 언급하지 않음. 이것이 가장 큰 자산이자 즉각적 개선 포인트.

**현재 과잉 설계인 부분:**
2단계 생성(분석 메모 → 해설)은 API 비용 2배 + 복잡성 증가로 현 단계에서는 오버엔지니어링.

## 4. 개선 우선순위 및 실행 계획

### 목표 흐름
```
계산 결과 → ContentLoader 조회 → 관련 콘텐츠 포함 → GPT 해석 생성
```

### 1순위: ContentLoader → 프롬프트 주입 (즉시)

프로젝트 고유 자산 활용. 일반 GPT 사주 해석과의 차별화 핵심.

```python
# prompt_builder.py에 추가해야 할 것
ilgan_content = content_loader.get_ilgan(day_gan)     # 예: "갑목 일간: ..."
gyouk_content = content_loader.get_gyouk(gyouk)       # 예: "정관격: ..."
yongsin_content = content_loader.get_yongsin(...)      # 예: "수 용신: ..."
```

### 2순위: 핵심 판단 요약 블록 추가

`yongshin.py`, `ohang.py`에서 이미 계산된 결론값을 프롬프트에 명시.

```python
analysis_summary = """
## 핵심 판단 요약
- 일간: 갑목
- 월령: 신월
- 신강약: 중약
- 오행 특징: 금이 강하고 수가 다소 부족함
- 핵심 포인트:
  1) 월령상 일간이 다소 약해지기 쉬움
  2) 관성의 압박이 강하게 작용할 수 있음
"""
```

### 3순위: 질문 우선 재구성 + 출력 형식 표준화

```python
# 프롬프트에 추가할 규칙
"- 사용자 질문이 있는 경우, 해당 질문과 직접 관련된 항목을 가장 자세히 설명할 것.\n"
"- 관련 없는 항목은 짧게 요약할 것.\n"
"- 전체 항목을 균등한 분량으로 쓰지 말 것.\n"
```

### 나중에 고려: 2단계 생성, 카테고리별 시스템 프롬프트

질문 카테고리(general / career / love / money / health / family) 분리 후
카테고리별 가중치 조정 → 서비스 성숙 후 적용.

```
  - 신강약, 월령, 오행 과부족, 핵심 십신

## 사용자 질문

## 작성 규칙 및 출력 형식
```
